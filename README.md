# Android Vision Control Bot (Research Project)

본 프로젝트는 안드로이드 기기 환경에서 이미지 인식(Computer Vision)과 기기 제어(ADB) 기술을 결합하여 자동화 로직을 연구하기 위한 교육용 도구입니다.

## 🚀 주요 연구 기능

- **동적 해상도 분석**: 기기의 물리적 해상도를 실시간으로 감지하여 좌표 체계를 비율(%)로 변환하는 알고리즘 적용.
- **입체적 탐색 알고리즘**: 상하좌우 및 복합 경로를 통한 화면 데이터 훑기 기능.
- **안전 여백 제어**: 특정 영역의 오동작을 방지하기 위한 사이드 마진 활용 로직.
- **이미지 및 텍스트 복합 인식**: Tesseract OCR과 OpenCV 템플릿 매칭을 결합한 객체 탐지 기술.
- **지능적 상태 복구**: 기기의 연결 상태나 앱 실행 상태를 감시하여 자동으로 표준 상태로 복구하는 예외 처리 루틴.

## 🛠 시스템 요구 사항

1. **Software**:
   - Python 3.x
   - ADB (Android Debug Bridge) Utility
   - Tesseract OCR Engine

2. **Configuration**:
   - `.env` 파일을 통한 환경 변수 관리
   - `assets/templates/` 경로 내 분석용 샘플 이미지 관리

## 📋 사용 방법 (CLI)

```bash
# 연구용 봇 가동
python3 main.py

# 데이터 수집용 캡처 유틸리티
python3 capture.py
```

## ⚠️ 고지 사항 (Notice)

- 본 프로그램은 개인적인 **기술 연구 및 학습 목적**으로만 설계되었습니다.
- 모든 자동화 기술의 활용 책임은 사용자 본인에게 있으며, 플랫폼의 이용 약관을 준수할 것을 권장합니다.
- 실제 사용자와 유사한 행동 패턴을 모사하기 위한 변칙 대기 로직이 포함되어 있습니다.
