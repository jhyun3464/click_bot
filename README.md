# OKBot: 울트라 불도저 모드 (Galaxy Z Fold 7 최적화)

이 프로젝트는 안드로이드 기기(특히 갤럭시 Z 폴드 7)에서 OK캐시백 앱의 포인트를 자동으로 수집하기 위한 공부용 매크로 프로그램입니다.

## 🚀 주요 기능

- **해상도 자동 감지**: 연결된 기기의 해상도를 읽어와 모든 터치와 스와이프 좌표를 비율(%)로 계산합니다. (어떤 폰이든 작동!)
- **입체적 탐색 (Patrol)**: 단순히 아래로만 내리는 게 아니라 좌/우/위/아래 및 정지 스캔을 랜덤하게 섞어 화면 전체를 훑습니다.
- **좌측 여백 공략**: 중앙 광고를 피하기 위해 화면 좌측 가장자리를 잡고 스크롤하는 '안전 손잡이' 로직이 적용되었습니다.
- **초반 광고 돌파**: 앱 실행 직후 나타나는 대형 광고를 자동으로 밀어버리고 본문으로 진입합니다.
- **지능적 탈출**: 일정 횟수 이상 타겟이 발견되지 않으면 뒤로가기를 연타(5~7회)하여 다른 메뉴로 이동합니다.
- **이미지 & 텍스트 동시 사냥**: 캡처된 이미지(P 아이콘 등)와 텍스트(적립, 받기 등)를 모두 인식하여 사냥합니다.

## 🛠 설치 및 설정

1. **필수 도구**:
   - Python 3.x
   - ADB (Android Debug Bridge)
   - Tesseract OCR (설치 후 환경 변수 설정 필요)

2. **환경 설정**:
   - `.env` 파일에 ADB 경로와 타겟 키워드를 설정합니다.
   - `assets/templates/` 폴더에 사냥할 이미지(PNG)를 넣습니다.

## 📋 실행 방법

```bash
# 봇 가동
python3 main.py

# 이미지 캡처용 유틸리티 실행
python3 capture.py
```
